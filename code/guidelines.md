# Personal Budget Tracker

*Domain: Fintech / Consumer*
A privacy-first personal finance app that runs entirely in the browser with no account needed. Users log income and expenses across configurable categories and see a live breakdown: a doughnut chart of spending by category, a monthly trend line, and a running balance. All data is stored in localStorage.

## Tech highlights:
	• localStorage for persistent, private storage
	• Chart.js for doughnut and line charts
	• CRUD interface for transactions (add, edit, delete)
	• Monthly and yearly aggregation logic
	• CSV import and export

## Business value:
A privacy-conscious alternative to cloud finance apps. No sign-up, no data sharing, works offline. Directly useful to any student or individual.

## UI design focus
Three-panel layout: transaction list on the left, category breakdown chart centre, monthly trend chart right. A top summary bar shows current month income, expenses, and net balance.

## Stretch goals:
Recurring transaction support. Budget limits per category with overspend alerts. Dark mode toggle persisted to localStorage.
